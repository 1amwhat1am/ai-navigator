# AI-Навигатор

Бесплатный вводный курс об искусственном интеллекте для людей без опыта программирования. Пять уроков, около 50 минут, простые объяснения и практика. Интерфейс полностью на русском языке.

## Запуск

Приложение не требует сборки, авторизации, сервера приложений, ключей API или установки зависимостей. Откройте `index.html` в современном браузере.

Для предсказуемого сохранения данных рекомендуется открывать сайт через локальный статический сервер. Из каталога репозитория выполните:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте **http://localhost:8000**. В облачном окружении используйте предварительный просмотр порта **8000**, если он доступен. Остановка сервера — `Ctrl+C`.

Это только способ раздачи файлов: вся логика и данные остаются в браузере. Сайт также можно разместить на любом статическом хостинге. Для работы приложения не нужны внешние шрифты, библиотеки или сетевые запросы к AI-сервисам.

## Структура

```text
index.html            Главная страница, навигация, SVG-иллюстрация и информационные окна
styles.css            Оформление, адаптивные сетки и состояния фокуса
app.js                Материалы 5 уроков, переходы, прогресс и localStorage
tests/acceptance.cjs   Автоматические браузерные проверки
README.md             Запуск, правила хранения данных и отчёт
```

## Реализовано

- Главная страница с пятью доступными уроками и общим прогрессом.
- Отдельный экран каждого урока: материал, примеры и практическое задание с самопроверкой.
- Темы: основы AI, составление запросов, работа с текстом, описание изображений, проверка ответов и защита данных.
- Явная отметка прохождения и её отмена. Открытие, чтение и переход к следующему уроку не меняют прогресс.
- Прогресс = число пройденных уроков / 5 × 100%. Один урок — 20%.
- Сохранение прогресса, восстановление после перезагрузки и синхронизация вкладок одного сайта.
- Кнопка продолжения с первого непройденного урока, прямые ссылки вида `#lesson-2`, переходы вперёд и назад.
- Копирование примеров запросов. Если буфер обмена недоступен, текст выделяется для ручного копирования.
- Адаптация для смартфонов и компьютеров, навигация с клавиатуры, видимые состояния фокуса, поддержка уменьшения анимации.
- Информационные окна «Как это работает» и «О курсе».

Практика самостоятельная: вводить ответы или подключать сторонний AI-сервис необязательно. Приложение не генерирует тексты и изображения и не оценивает выполнение заданий автоматически.

## Хранение прогресса

Используется `localStorage`, ключ `ai-navigator.progress.v1`. Формат:

```json
{"version":1,"completedLessonIds":[1,3]}
```

Учитываются только целочисленные ID существующих уроков; дубликаты не увеличивают прогресс. Повреждённые данные не мешают открыть курс, а следующая успешная отметка восстанавливает корректный формат.

Данные привязаны к браузеру и адресу сайта. Другой браузер, устройство, порт или адрес (`localhost` и `127.0.0.1`) имеют отдельное хранилище. Очистка данных сайта удаляет прогресс. Для `file://` правила хранения различаются между браузерами; при таком запуске рекомендуется проверить сохранение самостоятельно или использовать статический сервер.

Если хранение запрещено или переполнено, сайт показывает предупреждение. В этом случае можно продолжать учиться и менять отметки в памяти, но новые изменения могут исчезнуть после перезагрузки. В приватном режиме браузер обычно удаляет данные после закрытия сеанса.

## Проверки

В ходе разработки выполнены `node --check app.js`, `node --check tests/acceptance.cjs`, `git diff --check`, проверка уникальности HTML ID и наличия локальных CSS/JS. Браузерные сценарии выполнены в Chromium через Playwright по HTTP; скриншоты главной страницы просмотрены на ширине 1440 и 390 пикселей.

Автоматические проверки покрывают 17 групп сценариев:

| Критерий | Проверка | Результат |
| --- | --- | --- |
| КП-01 | На главной ровно пять уроков, изначально 0% | Пройдено |
| КП-02 | Все уроки открываются, содержат материал и практику | Пройдено |
| КП-03 | Отметки по шагам меняют прогресс: 20, 40, 60, 80, 100% | Пройдено |
| КП-04 | После перезагрузки сохраняются проценты и отметки | Пройдено |
| КП-05 | Отмена уменьшает прогресс вплоть до 0%, результат сохраняется | Пройдено |
| КП-06 | Нет горизонтальной прокрутки на 320, 375, 390, 768, 1024 и 1440 px | Пройдено |

Дополнительно проверены: отсутствие автоматической отметки при чтении; кнопка продолжения; переходы и история браузера; переход к содержимому с клавиатуры без закрытия урока; неизвестный адрес урока; дубликаты и невалидные ID; восстановление после повреждения JSON; обновление между вкладками; открытие информационных окон клавиатурой, Escape и восстановление фокуса; копирование запроса; запрет и переполнение localStorage. Проверки не обнаружили необработанных ошибок JavaScript, неудачных запросов или внешних сетевых зависимостей.

### Повторный запуск тестов

Зависимости нужны только разработчику для проверок, а не пользователю приложения. Требуются Node.js, Python 3, Playwright и Chromium.

В одном терминале запустите сервер командой из раздела «Запуск». В другом, из каталога репозитория:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/acceptance.cjs
```

Если Chromium уже установлен в `/usr/bin/chromium`, скрипт использует его и установку браузера можно пропустить. Для другого адреса или исполняемого файла задайте переменные:

```sh
TEST_URL=http://127.0.0.1:8000 BROWSER_PATH=/usr/bin/chromium node tests/acceptance.cjs
```

Скриншоты сохраняются в `/tmp/ai-navigator-desktop.png` и `/tmp/ai-navigator-mobile.png`. Скрипт завершится с ненулевым кодом при ошибке.

## Что осталось

Все требования первой версии реализованы. Автоматические проверки запускались только в Chromium: Safari, Firefox и реальные мобильные устройства пока не проверены. Дополнительная попытка проверки прямого запуска через `file://` заблокирована политикой Chromium в облачном окружении (`ERR_BLOCKED_BY_ADMINISTRATOR`); для текущего предпросмотра здесь используется статический сервер на порту 8001. Синхронизация между устройствами, аккаунты и автоматическая проверка практики в эту версию не входят.
