# AI-Навигатор 2.0 — Sprint 1

Статус: требования первой итерации. Дата: 3 ноября 2026 года.
База: `feat/initial-ai-navigator-mvp`. Рабочая ветка: `feat/sprint-1-interactive-lesson-2`.

## Цель и границы

Превратить урок 2 «Как задавать вопросы AI» в интерактивный модуль с проверкой применения знаний. Сохранить дизайн, навигацию, пять материалов, практику и локальное хранение. В этой итерации тестирование вводится только для урока 2. Для уроков 1, 3, 4 и 5 сохраняются ручные отметки ознакомления и их отмена, без присвоения освоения.

Регистрация, сервер, платежи, внешние AI API, сертификаты и тесты остальных уроков в Sprint 1 не входят.

## Термины

- **Ознакомление / прочтение:** явная отметка материала в уроках 1, 3, 4, 5; для урока 2 — завершение теста с любым результатом. Старые ручные отметки MVP также учитываются как ознакомление. Это пользовательская история взаимодействия, а не доказательство знания или фактического чтения каждой строки.
- **Освоение:** хотя бы одна завершённая попытка актуального теста с результатом от 80%.
- **Попытка:** пять выбранных вопросов и ответы пользователя; становится результатом только после ответа на все вопросы и явной отправки.
- **Черновик:** начатая, но не завершённая попытка. Не даёт освоения или процентов ознакомления.

## Use Case UC-01 — Проверка знаний урока 2

**Актор:** учащийся без авторизации.

**Предусловия:** приложение загружено, выбран урок 2. Если нет сохранённого черновика, доступна кнопка начала. Сохранение между посещениями требует доступного localStorage.

**Триггер:** пользователь нажимает «Начать тест» или «Попробовать ещё раз».

**Основной сценарий:**

1. Приложение показывает правила: пять вопросов, порог 80%, точное совпадение набора в вопросах с несколькими ответами.
2. Выбирает пять разных вопросов из банка; гарантирует минимум две ситуации, один вопрос с одним ответом и один с несколькими.
3. Сохраняет набор и пустой черновик. При существующем черновике продолжает его вместо создания новой попытки.
4. Пользователь выбирает варианты. После каждого изменения приложение сохраняет черновик.
5. Пользователь нажимает «Проверить ответы».
6. Приложение проверяет, что есть допустимый ответ на каждый вопрос.
7. Начисляет один балл за точное совпадение ответа, без частичных баллов; рассчитывает процент.
8. Сохраняет набор, ответы, время завершения, версию банка и результат в историю. Убирает черновик. Отмечает ознакомление с уроком 2.
9. Показывает результат и разбор каждого вопроса. При результате от 80% урок получает «Освоен».
10. Обновляет обе метрики на главной; предлагает новую попытку.

**Альтернативные потоки:**

- **A1 — есть пропуски:** показать сообщение и перевести фокус к первому неотвеченному вопросу. Итог и запись в истории не создаются.
- **A2 — результат 0–60% без предыдущего успеха:** статус «Тест не пройден», освоение не увеличивается. Разрешить повтор.
- **A3 — неудача после успеха:** показать текущий результат и сообщение о сохранённом успехе; статус остаётся «Освоен».
- **A4 — перезагрузка или уход из урока:** восстановить тот же черновик либо последний результат; не начислять дополнительный балл за посещение.
- **A5 — запрет или переполнение хранилища:** показать предупреждение; продолжать в памяти до перезагрузки, не обещать сохранение.
- **A6 — старый прогресс MVP:** сохранить его в истории ознакомления; до первого сданного теста освоение равно нулю.
- **A7 — попытка изменена другой вкладкой:** не записывать ответы в чужой черновик; показать сообщение и обновить модуль.

**Постусловия:** завершённая попытка сохранена при доступном хранилище, результат отражён на главной. История предыдущих попыток и успехов не удалена.

## Бизнес-правила

- **БП-2.01:** освоение присваивается только по завершённому тесту с результатом ≥80%. Ручная отметка и открытие урока не являются подтверждением.
- **БП-2.02:** тест содержит ровно 5 уникальных вопросов из банка не менее 10. В каждой попытке есть минимум 2 ситуационных вопроса и оба типа выбора.
- **БП-2.03:** процент теста = количество правильных ответов / 5 × 100%. 3/5 = 60% — не сдано; 4/5 = 80% — сдано.
- **БП-2.04:** множественный ответ верен только при выборе всех правильных вариантов без лишних. Порядок выбора не важен.
- **БП-2.05:** результат не рассчитывается, пока не отвечены все вопросы. Черновик не считается попыткой в истории завершённых.
- **БП-2.06:** повторные попытки не ограничены программно. Неудача не отменяет ранее подтверждённый успех.
- **БП-2.07:** старые отметки — неизменяемая история ознакомления, не результаты тестов. Текущую отметку прочтения других уроков можно отменить, не удаляя эту историю.
- **БП-2.08:** ознакомление курса = число отмеченных прочитанными уроков / 5 × 100%; освоение курса = число уроков со сданным тестом / 5 × 100%.
- **БП-2.09:** в Sprint 1 освоить можно только урок 2; максимум освоения курса — 20%. Это ограничение явно объяснено на главной.
- **БП-2.10:** приоритет статусов: «Освоен» при любом успехе; иначе «Тест не пройден» при завершённой неудаче; иначе «В процессе» при открытии, черновике или ознакомлении; иначе «Не начат».
- **БП-2.11:** открытие может поставить только «В процессе», не меняя проценты. Запуск повторного теста не стирает историю.

## Нефункциональные требования

- **НФТ-2.01:** весь пользовательский интерфейс и обратная связь на русском языке.
- **НФТ-2.02:** адаптация к компьютеру и смартфону; отсутствие горизонтальной прокрутки от 320 px.
- **НФТ-2.03:** HTML, CSS и JavaScript без тяжёлых фреймворков, сборки и внешних сетевых зависимостей приложения.
- **НФТ-2.04:** без сервера приложений, регистрации, платежей, платных API и отправки ответов во внешние системы.
- **НФТ-2.05:** доступность с клавиатуры, семантические группы вариантов, видимый фокус и текстовая обратная связь; статус не обозначается только цветом.
- **НФТ-2.06:** localStorage с версией схемы и банка. При ошибке хранения приложение продолжает работать в памяти с предупреждением.
- **НФТ-2.07:** модульные проверки логики и браузерные проверки обязательных сценариев и регрессий MVP. Отчёт должен отличать выполненные проверки от непроверенных платформ.

## Формат и миграция

Текущий ключ: `ai-navigator.progress.v2`, поле `version: 2`.

```json
{
  "version": 2,
  "readLessonIds": [1, 2],
  "startedLessonIds": [1, 2],
  "legacyReadLessonIds": [1],
  "lesson2": {
    "attempts": [],
    "draft": null
  }
}
```

Черновик содержит `id`, `bankVersion`, `questionIds` и `answers` (ID вопроса → массив ID выбранных вариантов). Завершённая попытка дополнительно содержит `finishedAt`, `complete`, `correctCount`, `percent`, `passed`, `results`. При загрузке результат пересчитывается по сохранённым ответам; сохранённым флагам успеха не доверяем. Старые версии банка не интерпретируются как результаты текущего банка.

При отсутствии v2 читается `ai-navigator.progress.v1` с `version: 1` и `completedLessonIds`. Валидные уникальные ID копируются в ознакомление, начатые уроки и `legacyReadLessonIds`. История тестов остаётся пустой. Исходный ключ v1 не удаляется и не обновляется. При наличии v2 повторный импорт не выполняется. Данные формата новее v2 не перезаписываются.

## Ограничения первой итерации

Это локальная учебная самопроверка, а не защищённая аттестация. Ответы есть в клиентском коде, владелец браузера может изменить localStorage. Данные не синхронизируются между устройствами, очистка данных сайта удалит историю. Физическая ёмкость браузерного хранилища ограничена; при её исчерпании показывается предупреждение. Safari, Firefox и реальные смартфоны требуют отдельной проверки. При обновлении банка понадобятся правила сохранения результатов предыдущих учебных версий.
